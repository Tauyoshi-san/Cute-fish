# AQUA ALTER

餌と水槽環境の組み合わせで魚が進化する、クリック／タップ操作のアクアリウム育成ゲームです。

## かんたん起動（推奨）

フォルダ内の **「ゲームを起動」** をダブルクリックしてください。

- 初回だけ、ゲームに必要な部品を自動で準備します
- 準備が終わるとブラウザでゲームが自動的に開きます
- 2回目以降はすぐに起動します
- 終了するときは、ゲームのタブと起動時に現れた黒い画面を閉じます

Node.jsが入っていない場合は、公式インストールページが自動的に開きます。「LTS」をインストールした後、もう一度「ゲームを起動」をダブルクリックしてください。

## 開発者向けの起動方法

```powershell
npm install
npm run dev
```

## 初版の遊び方

- 魚をタップして餌を与える
- サンベリー3個で「ヒレアカリ」へ進化
- 水草2個＋プランクトン3個で「モスノセ」へ進化
- 3種類の餌＋ルミナ結晶で「ゲーミングメダカ」へ進化
- ゲーミングメダカに星くず3個＋ルミナ結晶＋水質90以上で最終進化
- 掃除、売却、ショップ購入、図鑑、ごほうび広告デモを利用可能

保存先はブラウザの localStorage です。
